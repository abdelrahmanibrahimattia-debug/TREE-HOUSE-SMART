## 🏛️ نظرة عامة على المنظومة
منظومة **System Tree House** هي منصة أعمال سحابية شاملة (Full-Stack ERP & CRM) مبنية بأحدث معايير الأمان السيبراني والكود النظيف. تدعم دورة حياة العميل والمشروع بنسبة 100% عبر 18 موديول معتمد، مع دعم من الدرجة الأولى لنوع التعاقد **"الفرش كامل"** وعملاء ما قبل السيستم.

---

## ✨ المميزات الرئيسية للمنظومة

1. **إدارة العملاء (CRM):** تسجيل ومتابعة العملاء، التحقق من الرقم القومي (14 رقماً)، ودعم كامل لشارة `🏛️ عميل قبل السيستم`.
2. **لوحة العرض الشاملة للعميل (Read-Only Showcase):** ملف 360° محمي من التعديل العفوي يجمع كل ما يخص العميل من بياناته وحتى أمر الشغل مع زر طباعة رسمي.
3. **الإضافة المجمعة للعملاء (Batch Import):** إضافة عشرات العملاء دفعة واحدة مع خاصية اللصق المباشر من جداول Excel و Google Sheets.
4. **المعاينات الميدانية (Inspections):** جدولة المواعيد، تبويبات منفصلة للمجدول والأرشيف، ورفع تقارير المقاسات ورسوم المعاينة.
5. **المقابلات والاستقبال (Showroom Reception):** تسجيل زيارات صالة العرض والميزانية التقديرية وتوليد كود عميل تلقائياً.
6. **التصميمات المعمارية والأجهزة (3D & Appliances):** ملفات SCN، اعتمادات العميل، وحصر ومطابقة الأجهزة الكهربائية (ثلاجة، بوتاجاز، بلت إن، شفاط بالأبعاد).
7. **المقايسات وجداول الكميات (BOQ):** محرك تسعير ديناميكي متعدد الأقسام مع تفقيط وحساب الخصومات.
8. **العقود الرسمية وجدول الأقساط (Contracts):** صياغة قانونية محكمة، تواريخ استحقاق الأقساط، وسندات الدفع.
9. **أوامر الشغل وخط الإنتاج بالمصنع (Work Orders):** مراحل التصنيع (تقطيع، تجميع، دهانات، تركيبات) ومتابعة الإنجاز.
10. **التوريدات والتسليمات الميدانية (Supply Delivery):** توريد أخشاب ورخام وأجهزة وتوثيق استلام الموقع.
11. **الخزينة والمدفوعات والسجل المالي (Finance):** إصدار سندات قبض وصرف، عهد، ومصروفات.
12. **شؤون الموظفين والرواتب (HR):** كشوف الموظفين، تحديد الرواتب الأساسية، وإحصائيات مسير الرواتب الشهرية.
13. **لوحة تحكم الصلاحيات للأونر (Admin RBAC):** مبدأ الحظر الافتراضي (Deny-by-Default) ومفتاح الإيقاف الفوري (Kill-Switch).
14. **سجل الأمان والعمليات (Audit Trail):** تسجيل كل عملية وعناوين الـ IP والتاريخ لمنع أي اختراق أو تلاعب.

## 🔒 بنية الأمان السيبراني (Cybersecurity)
* **المصادقة المشفرة:** تشفير كلمات المرور باستخدام خوارزمية `Bcrypt` (Salt Rounds = 12).
* **التوكنات الآمنة:** جلسات عمل مشفرة بـ `JWT` (JSON Web Tokens).
* **الحماية من الهجمات:** حماية الرؤوس بـ `Helmet` ومحدد معدل الطلبات `Rate Limiter` لمنع هجمات التخمين والحجب (Brute-Force & DDoS).
* **مناعة قواعد البيانات:** الاعتماد الكامل على استعلامات Prisma ORM المعلمة (Prepared Statements) لمنع حقن SQL بنسبة 100%.

## 🚀 التشغيل السريع محلياً (Local Run)

```bash
# 1. الدخول لمجلد الباك إند
cd backend

# 2. تشغيل السيرفر الموحد (يقدم الباك إند والواجهة معاً على المنفذ 5000)
npm start
```
🌐 افتح المتصفح على: **`http://127.0.0.1:5000`**

* **البريد الإلكتروني:** `owner@treehouse.com`
* **كلمة المرور:** `Admin@TreeHouse2026`
